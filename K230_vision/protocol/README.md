# K230—MSPM0 通信协议

本目录用于记录视觉结果的通信格式、时序、校验、超时和故障策略。

约束：

- 不占用八路循迹模块正在使用的 UART0。
- MSPM0 收不到有效视觉帧时必须回到安全状态。
- K230 不直接发送裸电机 PWM；只发送识别结果或高层事件。
- 电磁铁由 MSPM0 控制，上电、超时和故障时默认关闭。

## 钢珠识别帧

K230 使用 UART1，115200 bit/s，8N1，每 250 ms 发送一次状态。

多目标钢珠帧：

```text
$BALLS,count,id1,x1,y1,r1,score1,id2,x2,y2,r2,score2,...#
```

没有稳定钢珠：

```text
$BALLS,0#
```

字段说明：

- `count`：当前稳定跟踪的钢珠数量。
- `id`：本次运行期间分配给该钢珠的跟踪编号；短暂漏检后仍保持不变。
- `x`、`y`：钢珠中心，基于 640×480 图像坐标。
- `r`：钢珠在画面中的像素半径。
- `score`：由亮度反差、最高亮度和颜色饱和度计算的排序分数，范围 0～99；它不是神经网络置信度。
- 每帧实际以 `\n` 结尾，`#` 是协议内容结束符。

示例：

```text
$BALLS,3,2,248,450,17,86,4,390,408,16,85,5,388,352,12,82#
```

表示当前有三颗稳定钢珠，ID 分别为 2、4、5。

K230 侧出厂引脚映射：

- IO9：UART1 TX，连接 MSPM0 的独立 UART RX。
- IO10：UART1 RX，可选。
- 两块板必须共地。

MSPM0 不应因为单个 `BALLS` 帧立即吸合电磁铁。主控仍需检查比赛状态、目标位置范围和消息超时，并负责目标选择、吸合时间上限及故障关闭。
